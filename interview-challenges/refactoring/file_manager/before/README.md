Our goal is analyze and improve existing code. This is a classical whiteboard-style exercise.

Task 1. Open Python Fiddle (https://pythonfiddle.com/) copy the code into the editor. (5 points)
Task 2. What the current code is doing? Document the code using dostrings. (20 points)
Taks 3. Create a refactoring plan. Write it down by adding TODO comments. (25 points)
Task 4. Define test scenarios. Write them down.  (20 points)
Task 5. Create automated test for at least one scenario. (30 points)

Total points: 100 points
Passing score: 80 points
Time allocated: 10 minutes

Additional task (+30 points, additional 5 minutes): In case the refactoring plan is approved, refactor the code
