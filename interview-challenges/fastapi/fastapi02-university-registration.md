


An e-learning university needs to keep details of its students and staff, the courses that it offers and the performance of the students who study its courses. The university is administered in four geographical regions (England, Scotland, Wales and Northern Ireland).

Our task is to create API to enable the front-end development.


Task 1: Design data model for the system, using conceptual ER diagram.

Task 2: Create Student ORM model.

Task 3: Design REST API routes for managing students.

Task 4: Define route function for Create Student route.

Task 5: Explain the testing strategy.
